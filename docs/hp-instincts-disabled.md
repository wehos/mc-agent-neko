# 低血量反射已退役

低血量不再是身体夺权、任务中断或自主规划信号。这是代码级退役，不存在环境变量或启动参数可以恢复旧行为。

## 唯一允许的低血量动作

- 背包里已有食物且受伤、饥饿值低于自然回血线时，`auto_eat` 可以原地吃现成食物。
- 背包里已有可饮用的治疗或再生药水时，`auto_heal` 可以原地饮用。
- 这两条路径只消费现有库存；不会外出觅食、砍树找苹果、迁移、挖掘、筑墙、封顶、停工或改写当前任务。
- 喷溅/滞留药水和伤害、剧毒、凋零药水不会被当作治疗药水。

## 已退役的行为

- kernel 的低血灰区强派、危急解卷和 `surviveNow` 路由。
- arbiter 的绝对血量 vital 地板。
- modes 中的低血逃跑、驻守、冻身、脱困、夜间规划、watchdog 豁免和机会任务改道。
- supervisor 技能中的低血开工门、途中退出、回血等待、找食物、上浮、挖掘、迁移、封顶和故意死亡重置。
- `surviveNow` 与 `digReset` 技能保留同名兼容入口，但只返回 `retired`，不会控制 bot。
- 旧的启动器/环境开关已删除，不能重新启用这些路径。

## 仍然保留

- 死亡检测与重生处理。
- 基于事实威胁的动作：正在受伤、可达敌对生物、苦力怕、围攻。
- 环境危险：溺水、着火、岩浆、坠落、窒息。
- 任务结果和只读遥测中的血量记录；它们可以观察血量，但不能凭绝对血量阈值控制身体。

回归测试会检查旧开关、低血技能门和强制路由不会重新出现，并单独验证背包食物/治疗药水例外。
